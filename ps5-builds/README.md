# CT5 PS5 homebrew builds

These are unofficial ROM-free builds. You must supply your own legally obtained rom.sfc locally. The original source code and 17 commits are preserved in this branch.

* ct5-PPSA28360-build12.zip: standard PS5 software renderer, install under /data/homebrew/PPSA28360
* ct5-hd2d-PPSA28361-gpu-build2.zip: PS5 HD-2D GPU renderer, install under /data/homebrew/PPSA28361

HD-2D asset packs go under /data/ct-recomp/packs/. These archives have not been independently tested on PS5 hardware.
